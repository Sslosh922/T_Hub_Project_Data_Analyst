# T-Hub Startup & Operations Analytics

## 📊 Project Overview

An end-to-end Data Analytics project analyzing T-Hub startup, staff, service, payment, and access-log data.

The project covers data analysis using **Python, PostgreSQL, SQL, and Power BI** to generate insights about startup activity, revenue, service usage, facility access, and operational patterns.

## 🎯 Objectives

- Analyze startup and industry distribution
- Find top revenue-generating startups
- Analyze revenue by payment type
- Analyze startup service usage
- Study hourly facility footfall
- Analyze meeting room usage
- Identify unusual access patterns
- Detect potential overstay cases
- Forecast service usage
- Build an interactive Power BI dashboard

## 🛠️ Tools & Technologies

- **Python** – Pandas, Matplotlib, Seaborn
- **SQL** – PostgreSQL
- **Power BI** – DAX, KPIs, Charts, Slicers, Heatmaps
- **Machine Learning** – Decision Tree
